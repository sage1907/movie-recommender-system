# JPSStreaming: On-Demand Video Streaming Platform

Welcome to **JPSStreaming**, an on-demand video streaming platform that lets users enjoy high-quality video content seamlessly. The platform allows users to browse video collections, create watchlists, and continue watching from where they left off.

## Demo Video

For a detailed walkthrough of the application, watch the demo video:

[**Watch Video**](https://drive.google.com/file/d/1TL6e8sMKfdGD1C0AL0I32L9VB_GqlI17/view?usp=sharing)

## Features

- **User Authentication:** Secure login and registration for a personalized experience.
- **Video Playback:** Enjoy smooth video playback with options to adjust quality, volume, and fullscreen mode.
- **Watchlist Management:** Add videos to your watchlist to view later.
- **Continue Watching:** Resume videos from where you left off.
- **User Profiles:** Manage user profiles with personalized recommendations.
- **Search and Browse:** Effortlessly search for your favorite content and browse through curated categories.

## Technology Stack

- **Frontend:** React, CSS
- **Backend:** Node.js, Express.js, MongoDB

## Getting Started

To get started with the project locally, follow these steps:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/sage1907/movie-recommender-system.git
    ```

2. **Navigate to the project directory:**
    ```bash
    cd movie-recommender-system
    ```

3. **Install dependencies for both frontend and backend:**
    ```bash
    cd frontend
    npm install
    cd ../backend
    npm install
    ```

4. **Set up environment variables:**
   Create a `.env` file in the `backend` directory and configure the necessary variables (e.g., database URI, secret keys).

5. **Run the development servers:**
    ```bash
    // In the frontend directory
    npm run dev
    
    // In the backend directory
    npm run start-dev
    ```

6. **Access the application:**
   Open your browser and go to `http://localhost:5173`.
